Changelog

October 15, 2026

  • Named. The plugin is now called Interleaf everywhere — docs, UI strings, self-identification on the wire, and the plugin id, which is now interleaf. Existing installs update by re-adding the plugin (BRAT fetches it automatically) and removing the old message-bus folder.
  • Argon2id. New sealed notes derive keys with Argon2id instead of PBKDF2. Older notes still open exactly as before.
  • Icons. Full favicon and app-icon set across the site.
  • 255 unit tests passing.

October 14, 2026

  • interleaf.dev is live. Registered and shipped the same day.
  • Spec published — the OM-1 and OM-2 protocol documents, readable at /spec.md.
  • License — Business Source License 1.1, converting to GPL v3. Read it on the license page.
  • Mail. info@interleaf.dev is live — DKIM signed, DMARC p=reject, MTA-STS.
